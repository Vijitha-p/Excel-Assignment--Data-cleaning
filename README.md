# Excel-Assignment--Data-cleaning

# This project focuses on end-to-end data cleaning and formatting in Microsoft Excel. The raw dataset contained inconsistent text formats, missing values, typos, duplicate entries, and unformatted dates and prices. The goal was to transform it into a clean, analysis-ready dataset.
# Tools & Functions Used:
# MS Excel | LEFT, RIGHT, CONCAT, PROPER, TRIM, AVERAGEIF, IF, DATEVALUE, TEXT, Conditional Formatting, Remove Duplicates
